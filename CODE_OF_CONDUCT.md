# Code of Conduct / Código de conducta

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, assume good faith, and keep discussions about the code.

Report unacceptable behaviour privately to the maintainer, @PabloGonSan8, through a
[private security advisory](../../security/advisories/new) or a direct message on GitHub.
